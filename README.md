# PARFAITRANSIT

Site vitrine bilingue FR/EN pour les services d'achat de véhicules, transport international, transit et douane.

## Déploiement Netlify
Le dépôt est relié au projet Netlify **parfaitransit** sur la branche `main`. Pour une publication statique depuis la racine :
- Build command : laisser vide
- Publish directory : `.`
- Base directory : laisser vide

Le site doit contenir `index.html` à la racine, ainsi que les dossiers `css/`, `js/` et `img/`.

Les images de démonstration sont dans `img/`. Remplacez-les par des photos réelles en conservant les mêmes noms de fichiers, ou mettez à jour les chemins dans `index.html`.

## Langues et contacts
Le bouton FR/EN mémorise la langue choisie dans le navigateur. Vérifiez les coordonnées et l'adresse e-mail avant la mise en production.
